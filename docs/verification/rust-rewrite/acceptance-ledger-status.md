# §40 feature acceptance status — live Rust rewrite

Updated: 2026-10-27. This ledger is deliberately conservative. `VERIFIED_LOCAL` means the required Rust behavior is implemented and has current local test evidence; for user-facing flows it also has Windows native/UI evidence where stated. It does **not** automatically transfer verification to a later source SHA. `IMPLEMENTED_TESTED` means code + focused tests exist but some required UI/native/restart/platform evidence is still open. `PARTIAL` means a material slice exists but the master scenario is not complete. `MISSING` means no defensible Rust equivalent was found. `LIVE_BLOCKED` means the implementation exists but the required external/provider scenario cannot be accepted without real infrastructure evidence.

The Python capability snapshot remains `python-capabilities.json`; the current Rust router snapshot is `rust-capabilities-current.json`. Exact operation-name overlap is a prioritization aid, not the acceptance definition. Final acceptance still requires the scenario-specific success/invalid/persistence/conflict/privacy/UI/restart checks from the master prompt.

## Current release interpretation

This ledger is **not** a release waiver. Local Rust source/security gates and Windows native evidence exist, and predecessor hosted runs have separately exercised Windows, Ubuntu 22.04, macOS arm64 and macOS Intel package/GUI/keyring paths. The final repository-replacement SHA still requires one complete hosted candidate matrix. The mission then remains release-blocked by the protected real Iranian S3 conditional-write/encrypted-sync/second-device/UI sequence, which cannot run until real Liara environment variables/secrets are configured, followed by tag-triggered public release/download/latest verification. Signing is verified only when credentials exist; otherwise unsigned/unnotarized status must be stated. Linux-specific child-focus keyboard navigation is not inferred from failed synthetic Xvfb/WSLg input attempts. Python recovery tag `archive/python-final-c84cdf1` remains required until the Rust release is public and verified.
