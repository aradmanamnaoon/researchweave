# F39 initial analytic Bayesian mean slice — acceptance boundaries

This is **one deterministic analytic Bayesian model**, not completion of the requested Bayesian/multilevel statistical suite. It has no sampler, chain convergence, random seeds, learned observation variance, posterior predictive checking or multilevel effects. Do not present any such outputs as measured.

## Exact command

`statistics.bayes_normal_mean` is an `Effect::Read` operation in `researchweave-analysis`. It requires immutable `dataset_id`, exact `revision`, numeric `column`, `prior_mean`, `prior_sd`, and user-assumed known `observation_sd`. `credible_mass` is optional (default 0.95, permitted 0.5 to 0.999). The operation refuses unknown argument fields, nonfinite/unbounded inputs, empty valid observations, unknown columns/revisions and SDs outside strict numeric limits. Missing/null values are reported, not treated as zero.

```json
{
  "dataset_id": "<actual dataset id>",
  "revision": "<actual immutable dataset revision>",
  "column": "score",
  "prior_mean": 0,
  "prior_sd": 10,
  "observation_sd": 2,
  "credible_mass": 0.95
}
```

The `<actual ...>` values above are documented placeholders and not a runnable scientific result. `dataset_source_sha256` and `dataset_revision` in the output are loaded from the verified immutable data object, never provided by an untrusted caller.

## Mathematics and numerical contract

For independent observations \(x_i\sim\mathcal N(\mu,\sigma^2)\) with **known and user-specified** \(\sigma\), and prior \(\mu\sim\mathcal N(\mu_0,\tau_0^2)\):

\[
v_n=\left(\tau_0^{-2}+n\sigma^{-2}\right)^{-1},\qquad
\mu_n=v_n\left(\mu_0\tau_0^{-2}+n\bar x\sigma^{-2}\right).
\]

The engine computes the posterior mean using precision weights and a bounded streaming sample mean, and evaluates an equal-tailed normal credible interval from the exact posterior distribution. It reports model assumptions, data/missing counts and `mcmc_performed=false`/`multilevel_model=false` explicitly. No p-value or false frequentist confidence interpretation is attached to the interval.

Independent pencil-and-paper golden: six values 2,4,6,1,3,5 have mean 3.5; with prior mean 0, prior SD 10 and known observation SD 2, posterior precision is 0.01+6/4=1.51, posterior mean is 5.25/1.51 and posterior SD is sqrt(1/1.51). Rust tests assert these values numerically, credible interval symmetry, prior dominance and refusal of invalid parameters. Additional committed JSON fixtures are reproducibly generated by `scripts/qa/generate_f39_oracle.py` from an **independent Python stdlib** implementation using 55-digit `decimal.Decimal` arithmetic and `statistics.NormalDist` normal quantiles, covering four synthetic scenarios including a single observation, negative data and a wider 99% credible interval. The Rust implementation must match all four cases' mean, SD and two interval bounds at documented floating-point tolerances.
