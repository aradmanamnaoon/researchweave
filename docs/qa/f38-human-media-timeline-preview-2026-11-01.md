# F38 bounded local audio/video timeline preview (PARTIAL)

Source: `crates/researchweave-evidence/src/media_timeline.rs`, registered project-scoped read-only `evidence.media_timeline_preview` in the existing Evidence operation handler. This is a **manual annotation visualizer**, not a media player, transcription engine, or archival annotation manager.

Inputs: an existing nondeleted `sources` row of an explicitly accepted audio/video MIME, its exact source UUID and recorded SHA-256, a **caller-declared** positive duration no longer than 24 hours, and at most 96 human-supplied interval records. Each interval requires a canonical nonnil UUID, `start_ms < end_ms <= duration_ms`, Unicode-safe bounded code/coder/rationale strings, and strict field names. Intervals are sorted by start and identity. Project identity and expected revision are verified before preview. The operation checks the actual hash-addressed object file bytes after refusing missing, oversized, directory/symlink and invalid digest paths. There is no network access or local mutation.

Output: normalized human annotation list, deterministic project/source/revision-bound SHA-256 receipt, and accessible SVG with static labels and numeric interval bars. Untrusted annotation text is **never inserted into SVG**, preventing markup injection. The output explicitly discloses `source_object_sha256_verified=true` while `media_format_decoded=false`, `media_duration_verified=false`, `timestamp_alignment_verified=false`, `transcription_performed=false`, `playback_linked=false` and `persisted=false`. Object hash verification is **not** evidence that the bytes are a real decodable media format or that duration/timecodes match reality.

Synthetic unit tests construct a local project and an explicitly fake video object, checking Unicode labels/markup isolation, deterministic order independent digests, exact project scope/revision, no event writes, restart results, duplicate/invalid spans, and corrupted physical source refusal. The tests do **not** imply any real-media decoding, source licensing, participant consent, transcript fidelity or native GUI use. Acceptance remains PARTIAL until a consent-aware physical media import/playback UI, verified duration/time base, timestamp-linked transcript annotations, immutable approved coding history and cross-platform installed end-to-end tests are implemented.
