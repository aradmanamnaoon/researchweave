# Scientific and operational limitations

This is an **incomplete V2 domain implementation**, not a validated SPSS replacement. Out of 52 feature packages, only documented working slices of CSV and optional tabular import, views/variable metadata, missingness accounting, transformations, selected descriptive/inferential tests, Cronbach alpha, ordinary/robust OLS, limited effect pooling, fixed-unit coder agreement, annotation integrity, static plots and subprocess scripts are implemented. Required feature packages still lacking dependable tested implementations include multiple categorical tests and ANOVA variants, GLM/logistic, longitudinal/mixed effects, survival, factor analysis, advanced psychometrics, complex survey design, advanced time series, R cross-validation, generalized declarative DAG, chart presets, joined methods and wide-scale import/export compatibility.

Since the initial slice, added chi-square/Fisher, one-way ANOVA, Mann–Whitney, seeded bootstrap, exhaustive permutations, logit and Poisson GLM, PCA, k-means and hierarchical clustering, and ordered replay plans with hash-checked receipts. These methods have bounded synthetic-oracle tests but are not blanket validations for all study designs. Complex surveys, longitudinal/mixed effects, survival, factor/ordinal methods, time-series diagnostics, detailed export compatibility and UI integration remain unimplemented.

Now available in partial form: regular time-series parsing and ADF, scale scoring, power, OLS influence diagnostics, privacy-aware case/code joint displays, human-reviewed transcript reanchoring and Python syntax replay. Still missing: full time-series forecasting/ARIMA, sample-design effects and clustering, survival/longitudinal inferential methods, factor/measurement modeling, full metadata roundtrips, report authoring, UI integration, R installed-runtime or numerical parity verification, and strict per-operation schemas. Generated scripts assume matching local package versions and saved dataset revisions.

Survival, longitudinal, survey and factor methods now have limited tested implementations. Missing within these domains: competing-risk and left-truncated survival; flexible mixed-effects models, multiple-time DID/event-study; replicate survey weights, stratified FPC, multistage designs, nonresponse adjustment and calibration; ordinal/polychoric CFA and invariance. These services cannot be described as a complete research statistics product or full compliance with the 52-package prompt gate.

No claim is made that SPSS imports retain complete value-label or user-missing metadata. ODS needs `odfpy`; absent optional libraries produce appropriate errors. CSV imports intentionally preserve raw fields as strings until explicitly converted. No blanket imputation is done. Ordinary t-based confidence limits with infinite endpoints are not directly JSON serializable; consumers should render those endpoints explicitly. Dataset storage is disk-based per revision with JSON serialization and bounded import sizes; not optimized for million-row analytics. Project-level database revision concurrency, integrity rehash on read, cancel tokens and write-ahead log are not implemented. Interpreter execution provides a consent gate and timeout but no filesystem/network sandbox; never execute untrusted scripts. Statistical validation is limited to declared synthetic oracles and cannot guarantee applicability to a research design.
