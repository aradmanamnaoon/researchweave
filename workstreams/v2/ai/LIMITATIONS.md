# Honest limitations and unfinished work

The requested 50 AI feature packages and six stages have **not** all been implemented. Working slices: registry/provider calls, endpoint/offline policy, local source indexing and search, signed host authorization, durable sequential agent plans and receipts, and a minimal facade. There is no complete Ollama discovery, local inference, embeddings, vector search, robust citation generation, token streaming, adapters for Anthropic/Gemini, full connector integrations, OS secure secret store, encrypted sync, merge conflict resolution, complete UI wiring, robust audit log, or comprehensive security harness. Current source volume is substantially below the 6,000-line target.

Local immutable snapshot storage is implemented with checksum verification and sequential revision conflict tests, but cannot safely claim multi-process atomic compare-and-swap or authenticated encryption. The simulated folder backend must not be advertised as complete cloud sync.

An injectable embedder Protocol, fingerprinted exact-vector SQLite store and hybrid lexical/vector ranking now exist. No actual embeddings are generated by a built-in model, no approximate-nearest-neighbor backend is present, and a host must ensure vector production obeys the same privacy/approval policies.

The Markdown connector supports read-only, scope-gated local notes; it does not yet implement notes mutation, Zotero, Crossref/OpenAlex, MCP, WebDAV or S3 APIs. Imported note bodies are correctly tagged as untrusted but require policy enforcement in downstream agents.

Durable project-level token budgets and reservations exist as a separate host service. The current `ProviderRegistry.complete` path has not yet been bound to `BudgetStore` at the application composition root, and its admission token estimate is conservative rather than tokenizer-exact; unknown monetary pricing remains unknown.

Cryptography and OS keyring adapters have been exercised with the installed optional libraries and synthetic fixtures. They are not yet wired into the main facade or packaged as canonical project extras. Encrypted backup does not imply complete cloud sync: ETag/CAS, cross-process coordination, metadata confidentiality, platform keyring availability and credential lifecycle controls must still be assessed during integration.

PDF extraction accepts text-layer PDFs with a page and byte budget; scanned pages require separate OCR and text extraction cannot certify document truth. Re-indexing multiple PDF pages currently commits page by page, so interrupted multi-page updates may temporarily expose a partial set of refreshed page anchors; atomic batch replacement remains an integration task. The five domain journeys are headless and use deterministic fake provider transports; no real GUI, hosted AI account or consumer subscription path has been verified.

No live hosted model, real user files, or external network was used during tests. Do not enable experimental remote transport in a sensitive production installation until DNS rebinding, proxy handling, cancellation, audit and credential storage are completed.
