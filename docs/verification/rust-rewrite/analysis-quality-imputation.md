# Native dataset quality and simple imputation (2026-10-25)

The Python baseline exposes `dataset.quality` (read) and `dataset.simple_impute` (local write), alongside `dataset.export_csv` (sensitive export). This Rust slice adds quality and simple imputation within the existing immutable analysis store. `dataset.export_csv` is now separately registered as a `SensitiveExport` capability: it requires an exact approval token, returns a bounded formula-safe artifact with immutable revision/hash provenance, and performs no destination write; the trusted host remains responsible for final destination selection.

`dataset.quality` reports row-linked system/declared user-missing cells and duplicate non-null subject identifiers, in original row order with sorted subject groups. Each warning includes the immutable revision, parent and producing transformation. Optional `subject_column` enables duplicate checks. It returns `mutated=false`, per-kind counts and explicit configuration. Outcome regression residual outliers and train/test subject leakage from Python are **not yet supported**; providing extra configuration fields fails instead of silently pretending to run those checks.

`dataset.simple_impute` requires an existing `column` and `strategy` (`mean`, `median` or `mode`). Missingness includes null and metadata-declared user missing codes. Observed non-missing values alone determine the fill. Mean and median use finite numeric values; median sorts ascending and averages the middle two values for even sample sizes. Mode counts textual representations and rejects ties rather than choosing arbitrarily. No missing or no observed values, invalid column/strategy and nonnumeric values for numeric strategies are errors. A new immutable revision preserves all other data and records imputed source-row indices, fill value and a warning that single imputation understates uncertainty and is intended only for descriptive/sensitivity analysis. No randomized draws or claims of multiple imputation are made.

Deterministic golden: subjects `a,a,b,c,d` and scores `2,4,999,NULL,6` with `999` marked user missing. Quality yields two missing-row warnings and one duplicate-subject warning; mean and median fill both missing observations with `4`, leaving the original revision untouched. Tied mode, invalid columns, and no-missing cases fail. Verified with `cargo test --locked -p researchweave-analysis` (16/16 pass), `cargo fmt -p researchweave-analysis`, and `cargo clippy --locked -p researchweave-analysis --all-targets -- -D warnings` (pass). No live desktop or Python runtime parity execution is claimed.
