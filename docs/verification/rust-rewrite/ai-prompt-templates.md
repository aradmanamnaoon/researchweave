# Native AI prompt templates — 2026-10-25

The Python `PromptTemplateStore` versions named templates, requires a `{{project_text}}` placeholder in user text, rejects interpolation into system text, and renders project text only in the user role. The Rust AI crate now offers `PromptStore` with equivalent core boundaries, a project-scoped, bounded local JSON snapshot, and two host-dispatchable operations: `prompt.add` (`LocalWrite`) and `prompt.render` (`Read`). The host attaches its selected store using `AiOperationHandler::with_prompts`; the dispatch context supplies the project ID rather than caller arguments.

The store supports versioned add and exact/latest-version rendering, UTF-8 text up to 1 MB for the supplied project data, 32 KB system and 64 KB template limits, a maximum of 256 names per project, 128 versions per name, and 16 MB total snapshot. It performs temporary-file synced atomic replacement (with a Windows replacement path), but is plaintext and single-writer-per-path. Host filesystem permissions are required to protect any sensitive text. No credentials, network calls, tools, or model responses are stored by the prompt system. The implementation does not claim Python SHA-256 template digest parity or cross-process writer arbitration.

The command router gates `prompt.add` behind approval and audit. Preview validates fields without writing, including when the target file does not yet exist. `prompt.render` returns the trusted system text separately from the substituted user message; project-supplied instructions are never promoted to system text. Unsupported extra arguments are rejected. The regression test verifies approval denial, approved creation, preview without a file, correct user-role substitution, restart persistence and zero model requests. Agent plan/execute/cancel are intentionally not advertised: agent tool execution and persistent cancellation are not yet implemented safely inside the crate.

Windows verification: `cargo fmt -p researchweave-ai`; `cargo test --locked -p researchweave-ai` (**17/17 passed**); `cargo clippy --locked -p researchweave-ai --all-targets -- -D warnings` (**passed**). No root Cargo files, other crates, Python sources, commits or pushes were changed.
