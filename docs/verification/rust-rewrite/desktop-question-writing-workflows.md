# Desktop Question / Protocol / Writing / Review workflow slice (2026-10-25)

The 39-page Slint shell previously presented generic placeholders on Question (2), Protocol (4), Review (9) and Manuscript (19). This desktop-only slice replaces these four placeholders with operations already supported by existing backend crates, without altering any backend or database schema.

Question and Protocol expose a Refresh action that reads the actual persisted project question, design, privacy and revision via `project.open` using `ProjectHandler`, `CommandRouter`, and the shared local audit store. Nothing is fabricated and the screen explicitly states that editing question/protocol is not supported by the current project handler. A new deterministic Rust test creates an actual project and checks that the router-backed metadata reflects the persisted values.

Review and Manuscript provide a Unicode-capable title/body editor and an explicitly labeled **Save as project library source** action. This delegates to existing `library.source_add` with current project scope, argument-bound approval, persisted library storage and shared audit. The UI explicitly warns that this is a *library source record*, not a manuscript or formal screening decision. There is no fake manuscript/review mutation. Saved library sources can be browsed on the existing Library page. No unsaved draft autosave is claimed.

Validated on Windows: `cargo fmt -p researchweave-desktop` passed; `cargo test --locked -p researchweave-desktop` passed **10/10**; `cargo build --locked -p researchweave-desktop` passed. `crates/researchweave-desktop/tests/windows-uia-smoke.ps1` passed all six existing checks: managed project creation/reopening, accessibility naming/roles, Ctrl+K navigation, Persian Unicode, six activity roots, and UI responsiveness. The newly added note editors did not receive a dedicated UIA automation test yet. Strict `cargo clippy --locked -p researchweave-desktop --all-targets -- -D warnings` is blocked by an existing `clippy::manual_range_patterns` warning in **out-of-scope** `crates/researchweave-project/src/lib.rs:553`; no edit was made there.

Existing preferences, backup/recovery, source library, PDF and UIA functions were left intact. This task does not implement new project questions, protocol editing, formal systematic review or manuscript workflows beyond the supported metadata read/source-note save operations. No commits or pushes were made.
