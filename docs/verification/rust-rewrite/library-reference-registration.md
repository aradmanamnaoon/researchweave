# Rust library reference registration and export

The Python library facade supports bibliography parsing/import, reference listing, export, tags and collections. The native project schema is now v3 and contains structured references plus collection, tag, identity and citation-relation tables. Reference registration remains the low-level schema-native path; higher-level bibliography parsing/import and collection/tag behavior are now implemented in separate native slices rather than being claimed through aliases.

Added `library.reference_add` (local write), `library.references` (read) and `library.reference_export` (read). Registration accepts validated title, authors array, kind, optional year, DOI and JSON metadata, plus explicit BibTeX/RIS/CSL-JSON source format and original raw text. It saves the exact raw text and metadata to `reference`, with `status='unverified'`; output includes SHA-256 fingerprint and revision. This low-level registration path still trusts caller-supplied structured metadata; callers that need syntax parsing should use the newer `library.bibliography_preview` / `library.bibliography_import` operations documented in `library-bibliography-import.md`. Listing is bounded to 200 entries per request with offset pagination. Raw export retrieves the original exact bytes as UTF-8 string and digest.

The write checks project scope using the existing `LibraryHandler::store` verification, requires expected-revision CAS, denies replay via the unique request ID, and atomically inserts the reference, event hash-chain entry and project revision inside one SQLite transaction. Preview validates input without writing or changing revision. The operation is advertised as approval-required, as with existing source imports; dispatch approvals are enforced by the shared router. Reads reuse project event-chain verification. Existing source operations are unchanged.

Current Windows verification after the bibliography/collection/relation additions: `cargo test -p researchweave-library` (**8/8 passed**) and strict warnings-denied Clippy passed. The original registration regression still verifies preview isolation, persisted Unicode raw text, authors list, unverified status, replay and stale revision rejection, single revision and event after reopening.
