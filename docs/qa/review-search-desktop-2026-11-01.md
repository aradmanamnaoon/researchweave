# Offline review search drafting — native Review workspace

Date: 2026-11-01. UI source baseline `16f646c87c73e82915472a33985b20ff623ed326`. The companion core backend is supplied by the independent `review.search_strategy_build` evidence-module implementation and must be integrated into the **same source commit** before end-to-end acceptance.

The existing Review screen now scrolls and exposes a collapsed **Build database search strategy** control. Expanding it reveals separately labelled Population, Intervention, Comparison and Outcome concept inputs. Researchers separate synonyms within a category with semicolons and select one or more databases (`pubmed`, `scopus`, `web_of_science`), then explicitly choose **Build queries**. This is a project-bound `Effect::Read` operation, not an HTTP request or project mutation. Data scope is taken from the open canonical project; the frontend cannot substitute a project ID.

Native output is guarded against untrusted provenance claims: only a successful `review-search-strategy-v1` response with 1–3 recognized database queries, 64-hex source/query SHA-256 digests, `generated_offline=true`, `query_executed=false`, `retrieval_attempted=false`, no numeric result count, and `manual_verification_required=true` can display a verified draft. Anything else produces a refusal. The textual report explicitly says no database was queried or result counted and that the researcher must manually check Boolean syntax, field tags, indexing and dates before use. The display enforces a bounded length and resets when switching research projects.

The Review input/output panel is intentionally collapsed by default to avoid crowding existing screening workflow. The outer page uses the same scrollable layout pattern as Data View; results are displayed in a read-only selectable text editor so researchers can use native keyboard selection/copy rather than transcribing query text. It does not pretend to implement a live database connector, import an external search result, or append PRISMA search history.
