# Desktop preferences: density and UI scaling — 2026-10-25

The desktop already persisted dark mode, high contrast, compact density and reduced motion in `display-preferences.json` within the host data directory. This slice makes compact density change shared Slint spacing tokens (`space3`–`space6`) and adds an accessible, persisted interface text scale control with Smaller/Larger/Reset buttons. The scale adjusts the window default font size and remains bounded to 80–150 percent in 10-percent increments. Explicit hard-coded font sizes are not yet uniformly scaled, so this is **partial interface-scale coverage**, not OS-wide DPI or complete typography scaling.

`DisplayPreferences::read` loads legacy files without `ui_scale` as 100%, validates integer type, step and bounds, and rejects corrupted values. The existing temporary-file/backup replacement is used for writes and the initial startup applies the persisted scale. The unit test covers both 90% and 130% round trips, invalid 95/151 values, legacy default and existing theme/density flags. Accessibility-visible labels: Current interface scale, Decrease interface scale, Increase interface scale, Reset interface scale.
