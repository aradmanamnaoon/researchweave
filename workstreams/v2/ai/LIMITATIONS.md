# Honest limitations and unfinished work

The requested 50 AI feature packages and six stages have **not** all been implemented. Working slices: registry/provider calls, endpoint/offline policy, local source indexing and search, signed host authorization, durable sequential agent plans and receipts, and a minimal facade. There is no complete Ollama discovery, local inference, embeddings, vector search, robust citation generation, token streaming, adapters for Anthropic/Gemini, full connector integrations, OS secure secret store, encrypted sync, merge conflict resolution, complete UI wiring, robust audit log, or comprehensive security harness. Current source volume is substantially below the 6,000-line target.

Local immutable snapshot storage is implemented with checksum verification and sequential revision conflict tests, but cannot safely claim multi-process atomic compare-and-swap or authenticated encryption. The simulated folder backend must not be advertised as complete cloud sync.

An injectable embedder Protocol, fingerprinted exact-vector SQLite store and hybrid lexical/vector ranking now exist. No actual embeddings are generated by a built-in model, no approximate-nearest-neighbor backend is present, and a host must ensure vector production obeys the same privacy/approval policies.

No live hosted model, real user files, or external network was used during tests. Do not enable experimental remote transport in a sensitive production installation until DNS rebinding, proxy handling, cancellation, audit and credential storage are completed.
